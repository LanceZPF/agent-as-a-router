A small status tag — used for Governance budget status (OK/WARNING/CRITICAL) and the Live Stream fallback flag.

```jsx
<Badge tone="warning">WARNING</Badge>
```

Variants: `tone="ok" | "warning" | "critical" | "info" | "neutral"`. Pair with `⚠` prefix text for the fallback badge convention (`<Badge tone="warning">⚠ FALLBACK</Badge>`).
